# ecs/aulas-12-13/.gitignore anotado

## Visão geral
Arquivo de exclusão do Git para manter o repositório limpo de artefatos de build e arquivos de IDE. Ajuda a evitar commits de arquivos gerados automaticamente.

### Boas práticas
- **Ignorar artefatos**: evita poluir o histórico com arquivos gerados.
- **Exceções controladas**: mantém wrappers necessários (ex.: `maven-wrapper.jar`).
- **Compatibilidade multi-IDE**: regras para IntelliJ, Eclipse/STS, VS Code e NetBeans.

## Trechos com anotações
1. `target/`, `build/`: diretórios de build do Maven/Gradle.
2. `!.mvn/wrapper/maven-wrapper.jar`: mantém o wrapper no repositório.
3. Regras de IDEs: garantem limpeza em diversos ambientes de desenvolvimento.
